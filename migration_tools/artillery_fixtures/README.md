# Python reference fixtures

Generated by `.venv/bin/python -m migration_tools.artillery_reference` from actual
Python projectiles/combat/trait/terrain functions. `--stress` also regenerates the
eight longer 700-tick whole-battle references. Original Python sources and normal
MT19937 gameplay RNG are unchanged. Oracles use the documented shared SplitMix64.

Five full 20 s traces compare formation state, positions, strength, morale,
cohesion, reload, active projectiles and draw count; five direct physics traces
cover flight, terrain, forest, overflight and bounces. Nine specialist probes
compare the authoritative formulas. 1,000 golden vector norms catch changes to
integer substep boundaries. Eight stress fixtures compare all final regiment
states and RNG consumption at 12/24/36/60 regiments for each workload category.

C# tolerances are 1e-5 for physical/state values; norm/substep fixtures are exact.
This is deterministic supported-systems comparison, not full-AI battle parity.
